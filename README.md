# Todo List App

A simple Todo List application built with React Native, Expo and TypeScript.

This project was created as part of a school course.

## Features

- Display a list of tasks.
- Add new tasks.
- Mark tasks as completed or incomplete by pressing a task row.
- Show completed tasks with strikethrough text.
- Save tasks locally using AsyncStorage.
- Restore saved tasks when the application starts.
- Use separate components and explicit TypeScript types.
